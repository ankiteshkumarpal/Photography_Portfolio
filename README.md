# 📸 Photography Portfolio — Responsive Website

A fully responsive, modern **Photography Portfolio Website** designed for showcasing professional visual work with elegance and clarity.
This site is perfect for photographers, studios, freelancers, and creative artists looking to present their work online in a clean and impactful way.

---

## 🌟 Highlights

| Feature               | Details                                                           |
| --------------------  | ----------------------------------------------------------------- |
| 🖼️ Stunning Gallery  | Masonry layout with high-resolution imagery                       |
| 🗂️ Category Filters  | Pure CSS tab system — Weddings, Portraits, Travel, Product & more |
| 🔍 Lightbox Viewer   | Click any photo to view fullscreen (no JavaScript needed)         |
| 📅 Session Booking   | Includes a full booking modal/contact form                        |
| 📱 Fully Responsive  | Looks premium on mobile, tablet & desktop                         |
| ⚡Fast & Lightweight | Built using 0% JavaScript — only HTML + CSS                       |

---

## 🔥 Why this project is special

This project focuses on **visual storytelling**, strong typography, and a smooth browsing experience.
No frameworks, no bloated scripts — **just clean, handcrafted code**.
It loads fast, feels premium, and can easily be customized to match any photographer’s style.

---

## 🧭 Sections Included

* **Hero Intro** — bold and minimal call-to-action
* **Portfolio Categories** with CSS filters
* **Full Screen Lightbox** for photo viewing
* **Services + Pricing Plans**
* **About the Photographer**
* **Client Testimonials**
* **Contact Form + Booking Modal**
* **Footer with navigation & quick booking access**

## 🚀 How to Use

1. Download or clone the repository
2. Replace images with your own (recommended)
3. Update your name, branding, pricing, and bio
4. Host it on GitHub Pages / Netlify / Vercel — live in minutes
